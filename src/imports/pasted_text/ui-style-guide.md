# UI STYLE (VERY IMPORTANT)

Forget everything about traditional ERP software.

This application MUST NOT look like SAP, Tally, Busy, Oracle Forms, Bootstrap Admin, AdminLTE, CoreUI, Metronic, or any generic dashboard template.

Instead create a MODERN PREMIUM SaaS interface.

The visual quality should feel like products designed in 2026.

==================================================

Design this application as if it were a $100,000 commercial SaaS product.

Every screen should be Dribbble-quality and Figma Community-quality, but fully practical for real transport office work.

When users open the software, their first reaction should be:

"Wow... this looks like a premium product."

"This looks like a normal admin panel."

Focus on beautiful layouts, rich tables, premium cards, modern forms, smooth animations, and an enterprise-grade user experience.
